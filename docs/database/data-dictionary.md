# Database Data Dictionary

## Project: Expense Tracker
### AI-Powered Personal Expense Tracking, Forecasting and Financial Recommendation System

**Document Version:** 1.0.0  
**Status:** Approved  
**Date:** November 2026

## 1. Table: `users`
Stores primary user identity, authentication hashes, role entitlements, and currency localization preferences.

| Column | Data Type | Nullable | Default | Constraints / References | Description |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `id` | `UUID` | No | `gen_random_uuid()` | Primary Key | Immutable unique user identifier. |
| `email` | `VARCHAR(255)` | No | None | Unique, Valid Email | User login email address. |
| `password_hash` | `VARCHAR(255)` | No | None | BCrypt Hash | Secure salted password hash (work factor 12). |
| `full_name` | `VARCHAR(150)` | No | None | None | Display and legal name of the account holder. |
| `currency` | `VARCHAR(3)` | No | `'USD'` | ISO 4217 (3-letter) | Default accounting currency symbol (USD, EUR, INR, etc.). |
| `is_active` | `BOOLEAN` | No | `TRUE` | None | Flag for account suspension or active status. |
| `role` | `VARCHAR(50)` | No | `'ROLE_USER'` | None | Entitlement authority (`ROLE_USER`, `ROLE_ADMIN`). |
| `created_at` | `TIMESTAMPTZ` | No | `CURRENT_TIMESTAMP` | None | Audit timestamp when account registered. |
| `updated_at` | `TIMESTAMPTZ` | No | `CURRENT_TIMESTAMP` | None | Audit timestamp when account profile last changed. |

## 2. Table: `categories`
Defines the financial taxonomy for segmenting transactions and setting categorical budget allocations.

| Column | Data Type | Nullable | Default | Constraints / References | Description |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `id` | `UUID` | No | `gen_random_uuid()` | Primary Key | Unique category identifier. |
| `user_id` | `UUID` | Yes | `NULL` | FK -> `users(id)` ON DELETE CASCADE | Owner user. If NULL, denotes system-wide default taxonomy. |
| `name` | `VARCHAR(100)` | No | None | Unique per (user_id, name, type) | Category label (e.g., "Groceries", "Salary"). |
| `type` | `VARCHAR(20)` | No | None | Check: `type IN ('INCOME', 'EXPENSE')` | Transaction domain partition. |
| `color_hex` | `VARCHAR(7)` | No | `'#6366F1'` | Hex color code format | UI chart color rendering tag. |
| `icon_name` | `VARCHAR(50)` | No | `'Tag'` | Lucide icon identifier | UI icon identifier (e.g., 'ShoppingCart', 'Coffee'). |
| `is_system_default` | `BOOLEAN` | No | `FALSE` | None | True if standard seeded category; false if user-customized. |
| `created_at` | `TIMESTAMPTZ` | No | `CURRENT_TIMESTAMP` | None | Audit creation timestamp. |
| `updated_at` | `TIMESTAMPTZ` | No | `CURRENT_TIMESTAMP` | None | Audit last update timestamp. |

## 3. Table: `transactions`
Core financial ledger storing individual income and expenditure records.

| Column | Data Type | Nullable | Default | Constraints / References | Description |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `id` | `UUID` | No | `gen_random_uuid()` | Primary Key | Unique ledger entry identifier. |
| `user_id` | `UUID` | No | None | FK -> `users(id)` ON DELETE CASCADE | Tenant user owning the transaction. |
| `category_id` | `UUID` | No | None | FK -> `categories(id)` ON DELETE RESTRICT | Category classification. |
| `amount` | `NUMERIC(15,2)` | No | None | Check: `amount > 0` | Absolute monetary value. |
| `type` | `VARCHAR(20)` | No | None | Check: `type IN ('INCOME', 'EXPENSE')` | Cash flow direction. |
| `transaction_date` | `TIMESTAMPTZ` | No | None | None | Wall-clock date and time transaction took place. |
| `description` | `VARCHAR(255)` | No | None | None | Description text (e.g., "Trader Joe's groceries"). |
| `merchant` | `VARCHAR(150)` | Yes | None | None | Commercial entity or payee name. |
| `payment_method` | `VARCHAR(50)` | Yes | `'CARD'` | Check: `CASH, CARD, BANK_TRANSFER, UPI, OTHER` | Settlement channel. |
| `notes` | `TEXT` | Yes | None | None | Optional user memorandum or context. |
| `is_recurring` | `BOOLEAN` | No | `FALSE` | None | Flagged if generated by a recurring schedule. |
| `is_anomaly` | `BOOLEAN` | No | `FALSE` | None | Flagged if flagged as spending outlier by Isolation Forest. |
| `ai_categorized` | `BOOLEAN` | No | `FALSE` | None | Flagged if category was suggested via ML model. |
| `created_at` | `TIMESTAMPTZ` | No | `CURRENT_TIMESTAMP` | None | Audit row insert timestamp. |
| `updated_at` | `TIMESTAMPTZ` | No | `CURRENT_TIMESTAMP` | None | Audit row last modification timestamp. |

| Column | Data Type | Nullable | Default | Constraints / References | Description |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `id` | `UUID` | No | `gen_random_uuid()` | Primary Key | Unique budget identifier. |
| `user_id` | `UUID` | No | None | FK -> `users(id)` ON DELETE CASCADE | Tenant user. |
| `category_id` | `UUID` | Yes | `NULL` | FK -> `categories(id)` ON DELETE CASCADE | Category cap; if NULL, applies to overall monthly spend. |

| `period_year` | `INT` | No | None | Check: `2020..2100` | Target calendar year. |
| `period_month` | `INT` | No | None | Check: `1..12` | Target calendar month (1 = Jan, 12 = Dec). |
| `notify_threshold`| `NUMERIC(5,2)` | No | `80.00` | None | Percentage threshold (e.g. 80.00%) for warning triggers. |
| `is_active` | `BOOLEAN` | No | `TRUE` | None | Active monitoring flag. |
| `created_at` | `TIMESTAMPTZ` | No | `CURRENT_TIMESTAMP` | None | Audit creation timestamp. |
| `updated_at` | `TIMESTAMPTZ` | No | `CURRENT_TIMESTAMP` | None | Audit update timestamp. |

## 7. Table: `ai_insights`
Stores AI-generated intelligence alerts, unusual spending notifications, and financial recommendations.

| Column | Data Type | Nullable | Default | Constraints / References | Description |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `id` | `UUID` | No | `gen_random_uuid()` | Primary Key | Unique insight record identifier. |
| `user_id` | `UUID` | No | None | FK -> `users(id)` ON DELETE CASCADE | Tenant user. |
| `transaction_id`| `UUID` | Yes | `NULL` | FK -> `transactions(id)` ON DELETE SET NULL | Associated transaction (if anomaly or specific spend). |
| `insight_type` | `VARCHAR(50)` | No | None | Check: `ANOMALY_SPEND, BUDGET_OVERRUN_RISK, DISCRETIONARY_OPTIMIZATION, SAVINGS_OPPORTUNITY` | Type category of the insight. |
| `severity` | `VARCHAR(20)` | No | `'INFO'` | Check: `INFO, WARNING, CRITICAL, POSITIVE` | Priority level for UI alerting. |
| `title` | `VARCHAR(150)` | No | None | None | Short banner title. |
| `message` | `TEXT` | No | None | None | Detailed explainable recommendation body. |
| `metadata` | `JSONB` | Yes | None | None | Structured payload (e.g. baseline amounts, category ratios). |
| `is_dismissed` | `BOOLEAN` | No | `FALSE` | None | Dismissal status by user. |
| `created_at` | `TIMESTAMPTZ` | No | `CURRENT_TIMESTAMP` | None | Record generation timestamp. |

## 8. Table: `expense_predictions`
Logs historical machine learning forecasts for tracking model drift and performance audits.

| Column | Data Type | Nullable | Default | Constraints / References | Description |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `id` | `UUID` | No | `gen_random_uuid()` | Primary Key | Unique prediction identifier. |
| `user_id` | `UUID` | No | None | FK -> `users(id)` ON DELETE CASCADE | Tenant user. |
| `forecast_horizon_days` | `INT` | No | None | Check: `7, 14, 30, 90` | Forward projection window in days. |
| `projected_amount` | `NUMERIC(15,2)` | No | None | None | Predicted cumulative expenditure sum. |
| `lower_bound` | `NUMERIC(15,2)` | Yes | None | None | 95% confidence lower interval boundary. |
| `upper_bound` | `NUMERIC(15,2)` | Yes | None | None | 95% confidence upper interval boundary. |
| `confidence_score`| `NUMERIC(5,4)` | Yes | None | None | Statistical model confidence metric. |
| `model_version` | `VARCHAR(50)` | No | None | None | Active model artifact identifier (e.g. `xgboost-v1.2.0`). |
| `features_used` | `JSONB` | Yes | None | None | Snapshot of time-series features used at inference time. |
| `generated_at` | `TIMESTAMPTZ` | No | `CURRENT_TIMESTAMP` | None | Timestamp forecast was calculated. |
