# Expense Tracker - Frontend Module

## Overview
This directory contains the single-page application (SPA) for **Expense Tracker**, built with React 18, Vite, JavaScript, and Tailwind CSS.

## Technology Stack
- **Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Tailwind CSS, PostCSS, Autoprefixer
- **Routing:** React Router v6
- **HTTP Client:** Axios (configured with interceptors for JWT token lifecycle)
- **Data Visualization:** Recharts
- **Icons:** Lucide React

## Architecture & Design
Detailed frontend documentation is available at [docs/frontend/frontend-architecture.md](../docs/frontend/frontend-architecture.md).

## Planned Setup (Phase 2)

npm install
