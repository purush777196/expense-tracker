# Expense Tracker - Automation & Maintenance Scripts

## Overview
This directory houses operational, deployment, testing, and database seeding utility scripts for **Expense Tracker**.

## Planned Utilities
- `setup-dev-env.sh` / `setup-dev-env.ps1`: Automated developer workspace initialization.
- `seed-demo-data.sh` / `seed-demo-data.py`: Multi-tenant financial ledger fixture generator.
- `run-all-tests.sh` / `run-all-tests.ps1`: Unified test runner covering Spring unit/integration tests, React Vitest/Jest tests, and Pytest ML suites.
- `verify-schema.sh`: Flyway migration validation check.
